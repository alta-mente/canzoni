# Non C'è Vita Su Marte — Sito Web Ufficiale per lo Streaming

Sito web ad alto impatto visivo con design **Liquid Glassmorphism**, integrazione dello **Spotify iFrame API**, player fluttuante in frosted glass e vinile 3D interattivo per l'album **«Non C'è Vita Su Marte»** di **Alessandro Rocchi**.

---

## ✨ Caratteristiche Principali

- 🪐 **Design Liquid Glassmorphism**: Mesh gradient cosmici animati con polvere di stelle e sfere cromatiche reattive (tonalità marziane carminio, neon, ambra e viola profondo).
- 💿 **Vinile 3D Olografico Interattivo**: La copertina reagisce al movimento del mouse in prospettiva 3D con fuoriuscita del disco in vinile con solchi riflettenti e rotazione al play.
- 🎵 **Spotify iFrame API Integrata**: Controllo completo di riproduzione, pausa, traccia precedente/successiva e seekbar sincronizzata con il widget ufficiale di Spotify.
- 🎶 **Tracklist Interattiva (10 Brani)**:
  1. *Non C'è Vita Su Marte*
  2. *Perché Sei Dovuto Andare Via*
  3. *Rumore*
  4. *Non Sono Più Niente.*
  5. *Quello Che Resta*
  6. *Tu Sai Come Si Consola*
  7. *Mi viene da ridere*
  8. *Non Respiro Più*
  9. *Sognando di essere sveglio*
  10. *Balla la polvere*
- 📊 **Visualizzatore Audio Simulata**: Equalizzatore grafico a barre dinamiche che reagisce alla riproduzione.
- 🌌 **Sezioni Dedicated**:
  - **Il Concept**: Manifesto artistico dell'album e poetica dello spazio interiore.
  - **Crediti**: Informazioni dettagliate su produzione, testi, mix, master e artwork.
- 📱 **Dock Audio Fluttuante**: Barra di controllo fissa in frosted glass con seekbar, visualizer e pulsante per espandere il player Spotify ufficiale.
- 🔗 **Modal di Condivisione**: Copia link rapida con 1-click, condivisione istantanea su WhatsApp, Telegram, X / Twitter e apertura rapida nell'app Spotify.

---

## 🚀 Avvio Locale

Il server di sviluppo è già attivo su:
```bash
http://localhost:5173/
```

Per riavviarlo in qualsiasi momento:
```bash
npm run dev
```

Per compilare la versione ottimizzata di produzione:
```bash
npm run build
```

---

## 🌐 Deploy (Vercel, Netlify, Cloudflare Pages o GitHub Pages)

Il progetto è una Single Page Application (SPA) estremamente leggera e veloce:
1. Collega la cartella o la repository a **Vercel** o **Netlify**.
2. Il comando di build è `npm run build` e la cartella di output è `dist`.
